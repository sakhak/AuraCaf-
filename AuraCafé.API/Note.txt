=============== Troubleshooting API connection errors ===============

If the web app says "actively refused localhost:5100", the API is not
running. Start it first and keep the terminal open:

dotnet run --project AuraCafé.API --launch-profile http

The API must show this message before starting the web app:

Now listening on: http://localhost:5100

Then open a second terminal and start the Razor Pages web app:

dotnet run --project AuraCafé.Web --urls http://localhost:5200

Check whether the API port is open:

Test-NetConnection localhost -Port 5100

The result must show:

TcpTestSucceeded : True

If the API stops with a password error, set a password with at least
12 characters, including uppercase, lowercase, a number, and a symbol:

dotnet user-secrets set "SeedAdmin:Password" "Admin@!1234567890" --project AuraCafé.API

If port 5100 is already in use, find the process using it:

Get-NetTCPConnection -LocalPort 5100 -ErrorAction SilentlyContinue

Stop that application or use the already-running API. Do not close the
API terminal while using the web application.
